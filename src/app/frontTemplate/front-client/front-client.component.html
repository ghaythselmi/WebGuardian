SECURITY HEADERS

Understanding the score

The score shows how many of six recommended HTTP security headers the website sends. Each header counts equally, so each one is worth about 16.7 points.

A 90–100 B 75–89 C 60–74 D 40–59 F 0–39
  • Strict-Transport-Security (HSTS)Asks browsers to use HTTPS for future visits.
  • Content-Security-Policy (CSP)Restricts which sources can provide scripts, styles, images, and other page content.
  • X-Frame-OptionsHelps prevent other sites from embedding the page in a frame to trick visitors.
  • X-Content-Type-OptionsPrevents browsers from guessing a file’s content type, reducing MIME sniffing risks.
  • Referrer-PolicyControls how much page URL information is shared when visitors follow links.
  • Permissions-PolicyLimits browser features such as camera, microphone, and location access.

This score checks whether each header is present. It does not assess whether its value is configured correctly or securely.
